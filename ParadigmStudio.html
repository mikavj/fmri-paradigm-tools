About this tool

fMRI Paradigm Studio reads a block-design paradigm, shows its timing and its stimuli, validates it against the acquisition it declares, and converts it between the formats used by presentation software and analysis packages. It runs entirely in the browser. Files are read locally and nothing is transmitted.

View and edit togetherAcquisition parameters, session order, blocks, trials and stimuli, with a live preview and timeline that update as you type.
VerifyChecks file syntax and internal references, and compares the length the design produces against the volume count the file declares.
ConvertWrites BIDS, FSL, AFNI, SPM, PsychoPy, Presentation, OpenSesame and scanner-side formats, each stating what it does not carry.
CalibrateTurns a required on-screen size into the font size and picture dimensions to author at, for every display version.

Open the Information tab above for the format reference, what can and cannot be converted, and how the scanner trigger is handled by each package. No file is needed to read it.
