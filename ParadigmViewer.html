The Paradigm Viewer has been replaced

Its functionality is now part of fMRI Paradigm Studio, which also edits, validates and converts.

Open fMRI Paradigm Studio

Why this file no longer runs. It is retained only as a pointer, because it produced timing that is now known to be incorrect in several cases:

  • Playback ran at five times real time by default, so stimulus pacing could not be judged.
  • A trial containing both a show and a wait had its wait dropped from the expanded timeline, so the preview drifted ahead of the reported total.
  • A duration of zero was treated as zero length rather than as "held until the next stimulus", and overlap was treated as blocking. Both inflate the computed run length.
  • Stimulus positions were parsed but never applied, so everything was drawn centred.
  • The JSON paradigm format was not read at all.

All of these are corrected in Paradigm Studio, which is checked against the full reference paradigm set.
