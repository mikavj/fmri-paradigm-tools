The Paradigm Editor has been replaced

Its functionality is now part of fMRI Paradigm Studio, where the editor and the preview are on screen together.

Open fMRI Paradigm Studio

Why this file no longer runs. It is retained only as a pointer. It wrote files that differed from the originals in ways that were not always intended:

  • Included files were renamed after the paradigm on export, so a stimulus set shared between several paradigms lost its own file name.
  • XML comments were discarded, and element order inside a stimulus was normalised, which moves a position element away from the picture it belongs to and therefore changes which picture it places.
  • Variables referenced only in the acquisition settings were reported as unused.
  • The JSON paradigm format could not be opened or written.

Paradigm Studio writes any file you did not edit back from its original bytes, so opening a paradigm and saving it again leaves formatting, comments, indentation and character encoding untouched.

The original source remains in the repository history if it is ever needed: git log --all -- ParadigmEditor.html
